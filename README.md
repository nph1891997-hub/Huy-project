# Quản lý tài sản

App một file HTML để quản lý tài sản cá nhân. Giai đoạn 1: **vàng**.

## Cách dùng

1. Mở `index.html` bằng **Chrome** hoặc **Edge** (bấm đúp vào file). Không cần cài gì.
2. Lần đầu: bấm **Tạo file mới…**, lưu `tai-san.json` vào thư mục bạn muốn (nên để trong OneDrive/Google Drive). Từ đó mọi thay đổi tự lưu vào file này.
3. Những lần sau: bấm **📂 Mở lại tai-san.json** ở góc trên.

Có thêm **Xuất JSON** để sao lưu và **Xuất CSV** để mở bằng Excel.

Đặc tả chi tiết: [`docs/dac-ta-vang.md`](docs/dac-ta-vang.md).
